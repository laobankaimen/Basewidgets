# 基础控件与组件库 UI 设计规范

[文档首页](README.md)

BaseWidgets 对外提供可复用 Qt Widgets 控件和组件。规范的验收对象是公开头文件、组件行为、绘制、布局和安装包；`widgets_demo` 只展示用法并承载自检，不是待设计的业务软件。

## 范围与职责

| 范围 | 约定 |
|---|---|
| 平台 | Windows 10/11、Ubuntu/KylinOS/UOS；Linux 优先 X11，Wayland 非必需 |
| 工具链 | Qt ≥ 5.11 且 < 6、C++14；源码兼容版本与预编译库依赖分别声明 |
| 操作 | 鼠标与键盘优先，中文界面；保留 tr()、混排和现有 RTL 支持，触摸及完整英文翻译非必需 |
| 库职责 | 控件、主题、布局、窗口、模型接入、绘图、反馈、数据校验与有界显示缓存 |
| 调用方职责 | 数据来源与内容、业务流程、认证、采样/计算调度、存储与持久化 |
| Demo 职责 | 合成数据、接线示例和回归；页面布局、数据规模与假账号不构成库的全局限制 |

不要求调用方先提供真实采样率、数据库或业务数据，才能设计和验证基础控件。现有领域图表/计算扩展保留其单位与数学契约，基础窗口、输入、表格和容器不依赖该领域。10 通道、6 图表、6 小时等数字只适合做合成测试场景，不作为全库业务上限。

## 一、公开接口与组合能力

1. 对外能力必须在 `interface/basewidgets/` 声明，并由安装包实际导出；用安装后的头文件编译、链接验证，不能只靠 demo 运行判断可用。
2. 头文件可独立包含。明确父对象/所有权、借用指针有效期、GUI 线程约定、默认值、合法范围、失败返回和信号时机。
3. 保留已有签名；缺少确认状态等能力时优先增加兼容重载。不能用删除旧接口或静默改变返回值解决问题。
4. setter 区分数据设置与外观设置。改变图标、颜色、全选入口显隐等展示参数，不得清空选项、选择或业务元数据；需要重绘/重新布局时立即通知 Qt。
5. 程序赋值与用户操作可以有不同规则，但须明确。例如多选框程序赋值可恢复禁用项选择，用户不能操作禁用项；选择上限是否影响程序赋值不得靠调用方猜测。
6. 接收者可能在操作信号中销毁发送者。发信号后继续访问控件前核对实际生命周期；延迟回调使用上下文对象或弱引用。内部定时器、动画和模型有明确所有者。

## 二、主题与视觉层级

统一使用 NativeStyle、ThemeTokens 和 QPalette；不为单个页面拼接 QSS，不在业务回调散落颜色常量。自绘控件在主题变化后更新，但不重置数据、选择、输入或滚动位置。

| 用途 | 默认取色/行为 |
|---|---|
| 页面 / 浮层 / 面板 | `bg0()` / `bg1()` / `bg2()`，用层级而非大量高亮区分区域 |
| 输入 / hover / pressed | `bgCtrl()` / `bgHover()` / `bgPressed()` |
| 正文 / 辅助 / 占位 / 禁用 | `textPrimary()` / `textSecondary()` / `textPlaceholder()` / `textDisabled()` |
| 选中内容 | `Highlight` 与 `HighlightedText` 成对使用 |
| 主动作 / 危险动作 | `primaryButton()` / `dangerButton()` 与 `BrightText` 配对；不能把亮指示色直接铺作按钮 |
| 告警与状态 | 语义色加文字、符号或线型，不只依靠颜色 |

常用可读文字组合按 4.5:1 检查，禁用内容单独处理；这是项目配色基线，不是整个产品的可访问性认证。显式颜色覆盖的持续时间必须写入接口；例如 ToggleSwitch 的颜色是临时覆盖，主题变化或 `updateColors()` 恢复主题默认。

## 三、尺寸、图标与布局

所有尺寸使用 Qt 逻辑像素，不手动重复乘 DPR。优先字体度量、sizeHint、minimumSizeHint、sizePolicy 和布局，不用固定窗口尺寸掩盖内容溢出。

| 元素 | 当前默认基准 | 使用约束 |
|---|---|---|
| 按钮、编辑框、下拉框、数值框 | NativeStyle 最小高度为字体高度 + 12 | 平台基础样式需要更高时保留更高值 |
| 菜单文字项 | 字体高度 + 8，文字宽度 + 20 | 长文字可省略但保留可读名称 |
| 复选/单选指示 | 16px；标签间隔 6px | 指示器图形与整个可点击控件区域分开 |
| 标题功能图标 / Logo | 20px 图标槽；头像圆形占 90% | SVG 保留比例，在实际绘制目标渲染 |
| 标题纯图标按钮 | 默认 36px 宽 | 点击区域大于图形；不是触摸规格 |
| ToggleSwitch | 默认 44×24，固定尺寸策略 | 调用方显式分配更大区域时图形居中，较小时缩入边界；整个控件区域可点击 |
| 组件内部留白 | 复用现有布局和样式度量 | 由组件自身管理；不把 demo 卡片宽度、列数写成库限制 |

窄布局通过换行、伸缩、折叠次要操作或滚动适配，不缩小正文。长中文、英文单词、富文本形状的普通字符串、大字体及 RTL 不应遮住确认/关闭入口。复合控件应在独立窗口、表单、布局和弹窗中都能工作。

## 四、交互状态矩阵

| 类型 | 鼠标/按下 | 键盘/焦点 | 禁用/只读 | 状态保留 |
|---|---|---|---|---|
| PushButton / ToolButton | hover、pressed 与默认态可区分 | Space、助记键及默认按钮规则沿用 Qt；焦点与选中分开 | 不执行操作、不出现可操作 hover | 鼠标离开恢复；可勾选状态不丢失 |
| CheckBox / RadioButton / ToggleSwitch | 命中与绘制几何一致 | Space 切换，保留 Qt 排他/三态规则 | 用户不能改变值 | 代码赋值与视觉同步 |
| LineEdit / SpinBox 等 | 沿用 Qt 编辑规则 | Tab 顺序、标签 buddy、输入法、验证器可用 | 只读与禁用有区别 | 错误不抹掉待修正输入 |
| MultiSelectComboBox | 点击切换但保留弹层 | 列表 Space 切换；Enter/Escape 关闭 | 禁用项跳过；解除禁用可恢复 | 关闭保留已选择项并恢复摘要；关闭搜索也清理过滤 |
| TabWidget / SegmentedControl / 容器 | 默认采用安静样式，无整体 hover 底色 | 选中和键盘焦点仍可辨认 | 禁用导航不可激活 | 保留组件已有的显式 hover 开关 |
| 弹窗 / 菜单 | 外点、重复点击与入口按钮状态一致 | Escape 按各类弹窗契约关闭 | 不因焦点丢失残留按下态 | 清理搜索、鼠标捕获和临时状态，避免点击重放重开 |

除非接口明确为“草稿+确认”，不要擅自让 Escape 撤销已经立即生效的多选操作。对受控值、程序赋值和用户实际变更，信号是否发出、发几次、是否触发校验要明确记录。

## 五、文本、错误与对话框结果

- 调用方传入的普通字符串默认按纯文本展示；只有显式承诺富文本的接口才解释 HTML。
- 输入标签支持换行和 buddy，并给编辑器可访问名称。纯图标入口有名称和 tooltip；全文不会因视觉省略而丢失。
- 错误说明关联实际输入字段，焦点与辅助描述一致。有效重试清除可见错误及辅助描述，禁用色不用于承载仍需阅读的错误说明。
- 取消、确认空值、确认原值是不同操作。输入对话框通过 `bool* accepted` 重载表达接受状态；旧重载继续保留原返回约定。
- DialogUtils 提供便捷交互，FramelessDialog 供调用方接入自定义校验。确认/取消按钮文字和顺序沿用组件/平台约定，初始布局与位置在可见前确定。
- 文件和颜色选择器只提供选择结果；认证组件只发请求。具体处理成功与否由调用方决定。

## 六、数据视图与图形组件

模型的源索引、代理索引与持久索引不混用；选择、勾选、排序与固定位置分别表达。分页保留当前页和边界禁用状态，完整输入页码后提交，不逐字符跳页。

图形组件声明输入单位、有效范围、排序、缺样、容量及失败行为；领域组件可验证数学不变量，但不自行选定真实采样率、数据内容或存储策略。无效值、过期与零值分别展示，显示抽样不改变原始测量值。图表保存有界展示缓存，耗时 DSP/I/O 不进入 paintEvent。

主题更新不清空图形数据，不覆盖明确指定的业务颜色。导出图像前同步待绘制数据；坐标、命中、选区与实际绘图范围一致。组件的详细容量仍以公开头文件与[图表使用说明](components/chart-interaction.md)为准。

## 七、窗口、兼容与交付

Windows 原生坐标和 Qt 逻辑坐标分别处理，最大化与弹窗以目标显示器工作区为准。真实分辨率变化、混合 DPI、多屏热插拔、系统拖动及输入法/读屏软件需要目标桌面验收；offscreen 截图不能替代。

源代码最低 Qt 5.11，不表示 Qt 5.15 编译的共享库可以加载到 Qt 5.11。安装包传播实际构建 Qt 要求和 `cxx_std_14`；消费工程已预加载不兼容 Qt 时明确拒绝。公共工厂函数不仅要在源码编译，还应从安装后的公开头文件链接和调用。

库可以不构建/安装 demo。可选自检使用现有 DemoChecks 测试入口，测试条件错误时应明确报错。源码包、头文件、资源、许可证和文档保持可追溯；不强制引入额外业务后端或公开发行流程。

## 八、组件验收与检查落点

新增或修改组件至少核对：默认构造 → 配置 → 显示 → 用户输入 → 程序更新 → 主题/尺寸变化 → 隐藏/重复打开 → 销毁。按受影响行为选择测试，不要求每次重跑无关检查。

| 检查面 | 本项目入口 |
|---|---|
| 选择和弹层契约 | `multiSelectKeepsDataWhenSelectAllVisibilityChanges`、`multiSelectMouseKeyboardAndLimit`、`multiSelectSearchModeRestoresAfterClose` |
| 输入结果、文本与键盘 | `libraryInputDialogsReportAcceptedAndPreserveCancellation`、`libraryInputDialogBuddyMovesFocus`、`libraryLoginFieldErrorsClearOnRetry` |
| 对外链接和生命周期 | `publicColorPickerFactoryUpdatesBorrowedOutputAndRespectsOwnership`、`toggleSwitchOwnsAnimationAndCentersInAllocatedSpace`；另以安装树构建消费端 |
| 主题、禁用、焦点和比例 | 既有 NativeStyle/标题栏/控件测试；dark/light/sg-blue，窄/宽布局及 1/1.25/1.5/2 倍渲染 |
| 兼容与平台 | 实际 Qt 5.11 和常用 Qt5 构建；Windows/Linux 目标桌面人工验收 |

本次对照规范的主要缺口是多选框配置丢状态、输入结果无法区分取消、公开颜色工厂缺少导出、开关动画归属和设置后重绘、登录错误辅助状态以及包依赖声明；对应实现和测试已补齐。Demo 页面本身未作为改版对象。

后续可继续完善的组件能力：统一字段级/表单级错误的公开接口；让消息列表、详情和辅助文本完整共享严重程度/时间；为需要大字体或运行时切换语言的自绘组件增加逐项布局验收。这些扩展应保持原有 API 兼容，按具体组件验证后再落地。

修改完成后的交付说明包含可直接使用的提交摘要：简短标题、修改项、验证结果和未验证范围。只描述本次改动，不复制历史流水；组件用法更新在对应文档中，临时日志和测试截图留在构建目录。
