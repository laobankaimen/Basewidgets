# 界面设计规范

[文档首页](README.md)

BaseWidgets 面向长时间使用的数据分析与监控工作区。采用 Qt Widgets 的布局、编辑、键盘和模型/委托机制，通过 NativeStyle、QPalette 和 QPainter 绘制；“原生绘制”指 Qt 绘制路径，不等同于操作系统皮肤。

## 视觉层级

- 页面、面板、输入及弹出层使用不同表面色；正文、辅助、占位和禁用文字各有角色。可阅读的辅助信息不能用禁用色代替。
- 每个操作区突出一个主要动作；轻操作使用 Subtle，危险动作使用 Danger。颜色只表达语义，执行和确认由业务负责。
- 输入和按钮提供默认、悬停、按下、禁用、选中与键盘焦点反馈。普通容器保持安静，不因鼠标经过而整块高亮。
- 状态同时使用文字与形状。未读消息用实心点、侧线和加粗标题，已读用空心点；告警程度与读状态分别表达。
- 主题颜色来自 ThemeTokens 或 palette，不在业务页面散落 RGB 常量或拼接局部 QSS。文字/底色成对配置，常用可读组合以 4.5:1 为项目检查下限。

## 尺寸与布局

字体和几何使用逻辑像素及字体度量，不把 DPI 缩放重复乘入控件尺寸。SVG 和头像按最终绘制目标渲染，保留原始宽高比。

标题动作采用 20px 图标槽、统一网格和线宽；头像圆形采用 90% 光学占比，纯图标按钮的点击区域宽 36px。窗口控制图形使用统一中心基准。详见[标题栏](components/title-bar.md)。

窄窗口通过减少卡片列数、折叠次要动作、滚动内容适配，不缩小正文或遮住关键按钮。文件窗口优先保留列表，表单与底部操作紧凑排列；分页保留当前页、边界状态和跳转入口。详见[基础控件](components/basic-widgets.md)与[高级表格](components/advanced-table.md)。

## 交互与状态

- 弹窗可见性与入口按钮状态同步；外部点击、Escape 和重复点击的结果一致。根据锚点所在屏幕剩余空间定位，显示前完成初始布局。
- hover 不等于选中，鼠标离开后恢复；键盘焦点必须可辨认。输入有标签/可访问名称，无效提交在当前上下文解释原因。
- 输入页码或搜索条件时避免逐字符触发昂贵操作；目录加载、查询和认证的耗时工作不能阻塞界面事件。
- 登录、刷新、取消、导出等请求通过信号交给业务；控件不假定任务完成。演示、离线、无数据和未知数值明确显示，不能伪装成在线或零值。
- 监控数据标明单位和更新时间。本机时钟不表示数据新鲜度，设备连接与采集状态由业务来源更新。

## 组件边界

| 层 | 职责 |
|---|---|
| Core | 主题、绘制、标题栏、无边框窗口与屏幕位置 |
| Inputs / Views / Containers / Dialogs | 输入、数据视图、布局和反馈 |
| Acoustics | 统计、频谱和解调计算 |
| Charts / Gauges | 数据展示与业务交互信号 |
| 应用层 | 数据源、异步任务、认证、持久化与导航 |

Qt 父子对象管理 UI 生命周期，源模型及业务数据由应用明确持有；公开接口说明借用、接管和失败行为。控件与主题接口在 GUI 线程使用，工作线程结果通过 queued connection 交回。

主题源经构建期生成器形成内嵌资源，再由 StyleManagerAdapter → ThemeTokens/QPalette → NativeStyle 应用。生成器不链接 UI 库，生成物留在构建目录；图标、字体及许可证留在 assets。详见[主题与资源](guides/themes-and-resources.md)。

窗口位置统一使用 Qt 逻辑坐标，Windows 原生消息单独处理原生坐标。Wayland 的绝对位置由合成器管理；真实分辨率切换、混合 DPI 和多屏行为需在目标桌面验证。详见[多屏工作区](components/multi-screen.md)。
